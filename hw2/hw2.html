Overview

In this HW2 we pursue the general problem of Bayesian neural net (BNN) regression: that is, we'll try solve a regression problem using neural nets, where all unknown weights/biases get a probabilistic treatment rather than being point estimated.

We'll consider univariate regression, where we try to map "input" scalars \(x \in \mathbb{R}\) to "output" scalars \(y \in \mathbb{R}\), via a learned function \(f_{\theta}(x)\) parameterized by \(\theta\).

Prediction function and possible architectures

To define \(f_{\theta}\), we consider a feed-forward neural network (multi-layer perceptron) with \(L\) total layers (including the output layer and \(L-1\) hidden layers). We'll index each layer with integer identifier \(\ell \in 1, 2, \ldots \ell, \ldots L\).

A general neural network for regression with L total layers will have L-1 hidden layers, each one with different numbers of hidden units. We can specify the size of the hidden network as a list of integers, like this:

  • [] means there are no hidden layers and no hidden units (equivalent to linear regression)
  • [5] means there is one hidden layer with 5 units
  • [5, 3] means there are two hidden layers, the first has 5 units and second has 3 units.

To understand this specification, note that

  • the number of hidden layers (L-1) is equal to the length of the list
  • the size of the \(\ell\)-th hidden layer (counting up from 0, 1, ...) is given by the integer at position \(\ell\) in the list.

In code, we'll call this the architecture (arch) or the number of dimensions per hidden layer (n_dims_per_hidden_list).

Given a fixed architecture, the total size of variable \(\theta\) is fixed. Remember, \(\theta\) denotes all the weights \(w\) and bias parameters \(b\) of the network.

Goals

We'll assume we've observed a training set of \(N\) observations: \(\{x_n, y_n\}_{n=1}^N\), where each input \(x_n\) has size 1 and each output \(y_n\) has size 1.

We'll treat the parameters \(\theta\) and outputs \(y\) as random variables, via the Probabilistic Model for HW2 with prior \(p(\theta)\) and likelihood \(p(y | \theta)\) defined below.

Given the training data, we seek:

  • to sample weights from the posterior \(p( \theta | y_{1:N})\)
  • to make predictions for new inputs \(x_*\) via the posterior predictive \(p( y_* | y_{1:N})\)

Technical Background : Neural nets for regression

Prediction function \(f\)

We can evaluate \(f\) via a series of layers, one after the other.

Hidden layer 1: The 1st layer takes input of size \(1\) (because we assume we're doing univariate regression) and produces a vector \(h^{(1)}\) of size \(J^1\). The parameters of this layer are the weights \(w^{(1)} \in \mathbb{R}^{J^1 \times J^0}\) and the bias \(b^{1} \in \mathbb{R}^{ J^1}\).

Each hidden unit of layer one, indexed by \(j\), produces a scalar value \(h^{(1)}_{j}\) by multiplying the input vector \(x\) by a weight vector, adding a bias, and feeding the resulting scalar through an activation function:

$$ h^{(1)}_{j}(x, \theta = (w,b)) = \text{a}\left( b^{(1)}_{j} + \sum_{k=1}^{J^0} w^{(1)}_{j,k} x_{k} \right) $$

Activation function. Here, we'll assume the activation function \(a\) is tanh, the hyperbolic tangent function -- see numpy's np.tanh.

Hidden layers 2, 3, ... L-1: Each other hidden layer (indexed by \(\ell\)), takes input of size \(J^{\ell-1}\) and produces output of size \(J^{\ell}\). The parameters of this layer are the weights \(w^{(\ell)} \in \mathbb{R}^{J^{\ell} \times J^{\ell-1}}\), and the bias vector \(b^{\ell} \in \mathbb{R}^{J^\ell}\).

Each hidden unit of layer \(\ell\), indexed by \(j\), is produced by weight multiplication, adding a bias, then feeding through an activation function:

$$ h^{(\ell)}_{j}(x, \theta = (w,b)) = \text{a}\left( b^{(\ell)}_{j} + \sum_{k=1}^{J^{(\ell-1)}} w^{(\ell)}_{j,k} h^{(\ell-1)}_{k}(x,w,b) \right) $$

Final output layer: At the final layer with index \(L\), we take input of size \(J^{L-1}\) and produce a scalar predicted output. The parameters are weights \(w^{(L)} \in \mathbb{R}^{1 \times J^{L-1}}\) and bias \(b^{(L)} \in \mathbb{R}^{1}\).

The scalar output value \(f(x, w, b)\) is given as follows:

$$ f(x, \theta = (w, b)) = b^{(L)}_{1} + \sum_{k=1}^{J^{(L-1)}} w^{(L)}_{1, k} h^{(L-1)}_{k}(x,w,b) $$

Note: there is NOT any activation function applied to the output layer, because this is regression, and we desire the output to be any real value.

Special case when arch = []

Useful special case: If we set \(L=1\) and arch [], there are no hidden layers, and our proposed prediction model reduces to univariate linear regression, with just one scalar weight and one scalar bias parameter.

The prediction function in this special case is:

$$ f(x, \theta = (w, b)) = b_1 + w_{1} x \qquad \text{(when no hidden layers)} $$

Probabilistic Model

Our model consists of random variables for:

  • \theta : weights and biases
  • y : outputs of prediction

Below we define the prior and likelihood that together form the joint \(p(\theta, y)\).

For HMC, we also define auxiliary momentum variables \(\rho\), such that the expanded joint \(p(\theta, y, \rho)\) has the same distribution over \(\theta, y\) as the original model when we integrate away \(\rho\).

Prior: Beliefs about the weights

The prior is a distribution over weights (and biases).

Across all layers, we will generally assume a simple independent prior for each weight scalar value and bias scalar value, which is Gaussian with mean zero and standard deviation three:

\begin{align} p(\theta) = p(w, b) = \prod_{\ell=1}^L \prod_{j=1}^{J^{\ell}} \prod_{k=1}^{J^{\ell-1}} \mathcal{N}( w^{\ell}_{j,k} | 0, 3^2) \cdot \prod_{\ell=1}^L \prod_{j=1}^{J^\ell} \mathcal{N}( b^{\ell}_j | 0, 3^2) \end{align}

Why standard deviation of 3? Ideally might allow more flexibility, since it is "more uniform" than standard deviation of one, while still keeping weights and biases typically within a reasonable range of (-6, +6), which is +/- 2 standard deviations.

Likelihood: Beliefs about outputs given inputs and weights

The likelihood is a distribution over the output \(y_n\) (a scalar value) of the regression when given an input \(x_n\) (vector of size D) and some weights and biases.

We will model a dataset of size \(N\) as having drawn each output independently given its input and the weights.

Each independent density will be a Gaussian, where the scalar value produced by the feed-foward neural network -- \(f(x_n, w, b)\) -- is the mean:

\begin{align} p( y | \theta) = p(y | w, b) &= \prod_{n=1}^N p(y_n | w, b) \\ &= \prod_{n=1}^N \mathcal{N}(y_n \mid f(x_n, w, b), \tau^2) \end{align}

where \(\tau\) be a standard deviation hyperparameter.

Auxiliary momentum random variables.

For HMC, we expand our model by including momentum variables \(\rho\), with one scalar \(\rho_{j,k}^\ell\) for every weight scalar and one scalar \(\tilde{\rho}_{j}^{\ell}\) for every bias scalar.

We'll assume a zero-mean, unit-variance distribution over all such variables:

\begin{align} p(\rho) = \prod_{\ell=1}^L \prod_{j=1}^{J^{\ell}} \prod_{k=1}^{J^{\ell-1}} \mathcal{N}( \rho^{\ell}_{j,k} | 0, 1) \cdot \prod_{\ell=1}^L \prod_{j=1}^{J^\ell} \mathcal{N}( \tilde{\rho}^{\ell}_j | 0, 1) \end{align}
