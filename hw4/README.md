# HW4 Starter code

Starter Code for HW4 of Tufts CS 152 Bayesian Deep Learning in Spring 2026

Instructions: <https://www.cs.tufts.edu/cs/145/2026s/hw4.html>

Author: Mike Hughes

Sample Usage
------------
To train an autoencoder (AE) on MNIST for 2 epochs with learning rate 0.01

```
$ python hw4_training_on_mnist.py --method AE --n_epochs 2 --lr 0.01
```

Data
----
Be sure you download the associated 9MB MNIST dataset files in this starter repo.
